This release contains an **unsigned, device-only IPA** and its SHA-256 checksum.

Download `LocalWave-unsigned.ipa` below and sign it using your chosen iOS sideloading tool before installing it. An unsigned IPA cannot install directly on an iPhone. Your signing account determines expiry and renewal requirements. A Mac is not required to compile the source when using this download, though your sideloading tool may require a computer.

The app requires iOS 18.0 or newer. Imports use folders you select in Files. FLAC tags and artwork are read from native FLAC metadata; local availability is still required for playback.

This is a community sideloading release. It is not an App Store release, Apple notarization, or a signed distribution build.
