# Historical redesign implementation and qualification

This record covers the earlier iOS and Mac Catalyst implementation. Mac Catalyst has since been removed and replaced by the native macOS target in `MacApp.swift`. Its screenshots, simulator logs and platform-specific claims below are historical evidence for that version, not qualification of the current Mac app. See [Mac list qualification](perf-mac-list.md) for the current performance status.

Reference: [LocalWave redesign, version 4](https://artifacts.microapps.space/a/mh0ydns8mzyg). Reference HTML SHA-256: `5fb5615a8d8f587ec1fbf39033dddf4177374056049048a5251428ef98113d90`.

## Implementation

The historical `MainTabView` supplied one SwiftUI shell. Below 900 points it used the mobile deck and full-screen player; wider windows used the sidebar, content, collapsible Now panel and bottom transport. The current native Mac app has its own `NavigationSplitView` shell. The reference's older P4 native-macOS column-browser proposal was superseded by its Round 3 return to the sidebar layout.

The shared views bundle Host Grotesk and Geist Mono, draw the 5×7 matrix numerals in Canvas, supply ten deterministic fallback-cover families, and use the reference's square controls, waveform hairlines, baseline progress and signal playhead. Motion includes pressed keys, staggered entrances, matrix row changes, waveform reveal, favorite particles and player zoom. System Reduce Motion and the app preference disable motion together.

Library, folders, search, playlists, settings, onboarding, queue and track actions use repository data. Desktop tables support sorting and keyboard selection. Queue entries have independent identities, including repeated songs. AVQueuePlayer preloads the next two items; a shared AudioSessionController owns activation and interruption events. AVAssetReader produces 512 cached waveform peaks per song.

Source roots store bookmarks in SQLite. Tracks retain source-relative paths, and GUI and terminal playback use the same resolver. Source watching uses NSFilePresenter with foreground rescans. Coordinated copies stream into an atomic cache; pins and active/queued files are protected from the configurable LRU limit. Removing a source deletes its library metadata without deleting originals.

Known evicted iCloud files and recognized File Provider locations are indexed from names and resource metadata without hashing or opening their audio. After materialization, a source event enriches the same source-relative row from a verified cache while preserving favorites and playlist membership. Source-version checks invalidate an outdated cache without reading provider content. Availability has distinct on-device, in-cloud and unknown states. Generic providers that do not expose download status remain unknown; the opening-file animation is indeterminate when no measured provider progress exists.

The first-run demo now uses 92 actual synthesized AAC recordings across eleven albums, imported as one local source through the ordinary folder pipeline. The audio/catalog adds 101.50 MiB to the bundle. Installation stages owned files atomically, rechecks that the library is empty before import, and preserves existing libraries. The exact “Try the demo library” action appears for an empty library; existing data offers “Explore the library.” It does not fabricate cloud/provider status, pins, listening history or autoplay. M4A metadata now recognizes native album-artist, release-date, track and disc identifiers, including guarded big-endian binary indexes; existing ID3 and duration handling remain intact.

Compact Now’s More button now uses the same `LWTrackMenu` as Library rows, including the 56pt preview, complete grouped actions and Add to list submenu. Current playlist context excludes that list and enables membership removal; Play and Retry preserve the explicit current queue entry. Real missing-file → repaired CAF playback verifies duplicate identity and playlist context. Queue remains its ordinary sheet; desktop native context actions stay available.

Undo is a single Root notice, visible over Now and other pages. Its four-second lifetime, exact count/list label, one-shot action, successful “Undone” notice and failure retry preserve actual membership. Standard notices retain two seconds. Entry rises 10pt with the 240ms spring; exit fades over 140ms without moving. A stale completed undo cannot clear a newer removal slot. Empty user lists show the reference’s “Empty for now.” text and hide Edit while retaining the accessible Add songs action.

Selection now uses the reference’s compact header, 20pt checkboxes and four 62pt keys with a 2pt surround. It replaces the normal mini player/navigation deck while selecting. At accessibility text sizes the same keys use a two-column layout so labels remain readable. Folder selection reuses recursive saved-song/path metadata, excludes unknown unavailable files, and retains verified local copies when a source needs reconnecting. Individual folder checks remain functional rather than reproducing the prototype’s folder-selection tap defect.

Desktop selection uses the compact max-content strip, 32pt cells and 12pt sticky spacing. Short tables place it 12pt below the last row; long tables pin it 12pt above the viewport bottom. Successful membership removal clears selection centrally; Undo restores membership/order without restoring highlights. The visible compact Edit action uses the reference’s functional 44pt dot handles; native editing controls remain an accessibility alternate. This removes the native accessory’s 40pt separator truncation. Custom swiping follows the finger without a distance clamp, commits beyond 88pt and returns with the reference’s 420ms spring. A recognized swipe cancels its row button’s tracking, preventing the next row from playing after removal.

The desktop Up next header stays outside its independently scrolling rows. Queue identity changes use the 420ms out curve; inserted rows use a 6pt/240ms fade-rise, while Clear/Undo settle immediately as in the actual handlers. The interactive queue handle has its own accessibility element. Reduce Motion now clears explicit transaction animations as well as disabling implicit ones; a hosted animated control verifies both enabled and reduced behavior.

## Reproducing automated checks

Run `swift test` and `swift build -c release` for the shared modules and terminal executable. Run the `musicapp` scheme's unit and UI targets on an iOS simulator, and build the same scheme for My Mac (Mac Catalyst).

UI tests set `LOCALWAVE_UI_TEST_ID` to a fresh UUID. Debug builds then use an isolated database and preferences suite and generate an actual 30-second CAF fixture. `LOCALWAVE_UI_LIBRARY_COUNT` optionally creates up to 5,000 distinct library rows sharing that audio fixture. `LOCALWAVE_UI_AUTOPLAY=1` verifies that the native playback clock advances and writes `LOCALWAVE_PLAYBACK_VERIFIED=true` to stdout. These fixtures are unavailable in release builds.

`LOCALWAVE_UI_SOURCE=1` adds a real WAV in a dedicated fixture folder through the normal source/import services for folder-action UI tests.

`LOCALWAVE_UI_EMPTY_LIBRARY=1` with a valid isolated test UUID skips debug song seeding and opens real onboarding for the packaged demo gate. It has no effect on normal release behavior. After changing UI-test bodies, verify the trace/attachments match the new steps; a stale installed UI runner was encountered, and uninstalling only `com.test.test1.musicappUITests.xctrunner` restored the current body.
